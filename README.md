# Фронтенд для системы складского учёта (ВКР)

Веб-интерфейс для автоматизации складского учёта.

## Технологии

- Alpine.js 3.x — реактивный фронтенд (без сборки)
- TailwindCSS — утилитарная стилизация
- Font Awesome 6 — иконки

## Функционал

- Управление товарами, складами, контрагентами, спецификациями (BOM)
- Приход, отгрузка (FIFO), сборка готовой продукции
- Просмотр остатков, журнала движений, партий
- Отчёт COGS (себестоимость отгрузок)
- Уведомления о низких остатках

## Запуск

1. Склонировать репозиторий
2. Открыть `index.html` в браузере (или через Live Server)
3. Бэкенд должен быть запущен на `http://localhost:8080`

## Структура

```
front/
├── index.html              # Главная страница (SPA)
├── css/
│   └── style.css           # Кастомные стили и анимации
├── js/
│   ├── api.js              # Слой взаимодействия с REST API бэкенда
│   └── app.js              # Главный Alpine.js компонент (вся бизнес-логика UI)
└── pages/                  # Шаблоны динамических страниц
    ├── products.html       # Управление товарами
    ├── warehouses.html     # Управление складами
    ├── counterparties.html # Управление контрагентами
    ├── assemblies.html     # Управление спецификациями (BOM)
    ├── stocks.html         # Просмотр текущих остатков
    ├── movements.html      # Журнал движений
    ├── batches.html        # Партионный учёт (FIFO)
    ├── incoming.html       # Оформление прихода
    ├── outgoing.html       # Оформление отгрузки
    ├── assembly.html       # Операция сборки
    ├── cogs.html           # Отчёт COGS и прибыли
    └── alerts.html         # Уведомления о низких остатках

```

Разработано в рамках выпускной квалификационной работы.
